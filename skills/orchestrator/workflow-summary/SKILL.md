# Workflow summary

## Establish the record

Read the original task and the supplied history of completed stages. Identify the participants, their conclusions and the revisions those conclusions concern. Use referenced artifacts when they are available and needed to resolve a material ambiguity. Preserve project files.

Treat each participant's report as an attributed claim. Distinguish it from your own observations and from authoritative workflow state. A plan or suggestion becomes a decision only when the record shows it was accepted.

## Reconcile the history

Follow findings through later corrections and reviews. Keep unresolved findings visible. A later successful check resolves only the failure it actually covers. When a correction changes the revision, identify which approvals and checks apply to that revision and which describe an earlier result.

Account for each material part of the task using the available evidence. Identify conflicting reports, missing stages and required checks that were skipped or could not run. Preserve useful details such as failing inputs, successful check commands and resulting artifact references without reproducing the whole conversation.

Describe integration only from explicit workflow state or supporting evidence. A review approval or completed summary alone does not establish that a merge happened. If the record is insufficient, state the uncertainty and what information would resolve it.

## Deliver a concise handoff

Lead with the task's current result. Include the implemented outcome, important findings and fixes, verification evidence for the current revision, and remaining blockers or work. Omit empty sections and routine history that does not affect the conclusion.

Attribute reported test results and distinguish incomplete work from future suggestions. Give useful references without copying large artifacts or exposing sensitive data. Keep recommendations within the requested summary's scope. Use the host's completion format and keep completion of this report separate from completion of the underlying workflow.
