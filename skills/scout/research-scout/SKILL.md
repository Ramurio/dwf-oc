# Research source map

Search with the main terms, their synonyms, and relevant method or venue names. In a supplied corpus, use glob and grep to locate likely documents and read the relevant sections. With webfetch, query arXiv search or Crossref for papers and the GitHub API for artifacts. Open the primary source from each promising result. Prefer HTML full text or a supplied text extraction when the source is a PDF.

For a foundation search, follow citations back to the original claim and look for the accepted version. For a recent search, check first publication and revision dates against the task window. Identify preprints and changed results.

Keep one entry per source. Record its link, date, inspected sections, strongest supported claim, a limitation, and what the next researcher could verify. Mark leads found only in metadata or search results.
