# Проверка инструкции установки

Проверено 12 ноября 2026 года. Изменения ограничены документацией.
CLI, runtime, хранение состояния и интерфейсы workflow сохранены.

## Среда

- Linux x64, Bash, Node 26.3.0, npm 11.16.0.
- OpenCode CLI и клиент 2.2.5 из lockfile DWF.
- Свежая локальная Git-копия DWF под `/tmp/opencode/`.
- Отдельные временные HOME, XDG-каталоги, профили и БД OpenCode.
- Канонический `ramu-skills` получен через Git с разрешённым доступом машины.
  Проверенная ревизия `aef21081f016639beacc3467678ef2c6b0233727`.
  Её исходники сохранены без изменений.

Для управляемого первого запуска заменено только поле модели reviewer на локальный
`dwf-acceptance/planner`. Остальные поля взяты из документированного JSON.
Это проверяет маршрут CLI и сохранение результата. Доступность настоящей модели
проверяется после пользовательского входа.

При очистке управляемой пробы существующий harness встретил несовместимость своей
команды `ps` с окружением Linux. Сервис этой пробы остановлен отдельно через
штатный `Service.stop`. Все запущенные для установки тестовые сервисы остановлены.

## Что осталось вручную

- Получить доступ GitHub на новом компьютере. Проверенная копия DWF создана
  локальным clone. Установка зависимостей выполнена с временным пользовательским каталогом.
- Пройти OAuth или другой штатный вход OpenCode своим аккаунтом в профиле DWF.
- Выполнить пример с настоящей `openai/gpt-6.1-sol` и reasoning `high`.
- Повторить проверку команд после физической перезагрузки.
  В этой проверке использованы новые login-shell.
- Проверить macOS, ARM, Zsh и установку рекомендованного Node 24 LTS.
  Проверенный Node 26.3.0 входит в поддерживаемый диапазон DWF.

Полный `npm test` и `test:real` в этой задаче не запускались.
Учётные данные пользователя в испытания не переносились.
