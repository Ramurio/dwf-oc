## Цель DWF

Внешний агент получает обычное поручение пользователя, использует скилл dwf-oc и самостоятельно собирает подходящий workflow из ролей. DWF исполняет этот workflow, управляет переходами, контекстом участников, результатами и интеграцией.

Пользовательский интерфейс должен оставаться простым. OpenCode, SQLite и внутреннее устройство являются деталями реализации. Базовые роли — worker, reviewer, verifier и orchestrator. Автор workflow выбирает нужный состав. Сохранение контекста при повторном обращении к участнику включено по умолчанию.
