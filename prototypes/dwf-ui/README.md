# DWF UI — Вложенность · Astra

Интерактивный прототип визуализации DWF с демонстрационными запусками исследования и разработки. Исходный вариант создан дизайнером Astra через DWF, с уровнем рассуждения xhigh и обычной скоростью.

Из корня репозитория запусти локальный сервер.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory prototypes/dwf-ui
```

Открой [прототип в браузере](http://127.0.0.1:8000/). Выбирай запуск слева, нажимай на примитивы, переключай участников и историю вызовов. Панель показывает задание, результат, параметры модели, навыки и команду выбранной сессии.

Данные и идентификаторы OpenCode вымышленные. Интеграция с реальными запусками и жизненный цикл `dwf ui --start/--stop` остаются следующей частью разработки.

Оба независимых критика, Sol 6.1 и Astra с xhigh на обычной скорости, оценили итоговую версию на 10/10 за дизайн и 10/10 за удобство. Пройдено 4 раундов ревью. Хеш исходного HTML и сводка проверки находятся в [review-summary.json](review-summary.json).

Браузерные проверки выполнены в Chrome, включая узкие экраны, клавиатуру, историю сессий и копирование команд. Масштаб 200% проверялся через эквивалентные размеры viewport/DPR. Прототип работает без внешних ресурсов.
