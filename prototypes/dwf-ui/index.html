Each named row in a parallel group is an independent participant. The number shows all started calls. Joined dots show consecutive calls in the same session; separate dots show changed sessions. Select a row for the full history.

Direct replies share the outgoing route in the opposite direction. Longer cycles retain their actual endpoints. Crossings without a junction do not connect. Arrowheads show the destination.

Select a stop or participant to inspect its calls. History never changes current execution. Actual session IDs establish whether context continued; a fresh-context policy is not itself a session ID.

This is an offline design prototype, not a scheduler or editor. Every ID is fictional. Live DWF and OpenCode integration are future work.
